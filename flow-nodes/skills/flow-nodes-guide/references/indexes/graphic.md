# Graphic nodes

Each linked JSON file contains a parent group. Select the entry in `nodes` with the exact listed `typePath` for ports and properties. Prefer visible replacements for new flows.

- **Array Effect / List Blend** — Free. [JSON](../nodes/graphic/arrayEffect.json) · `node:graphic:arrayEffect:listBlend`. Blend a list of Graphics.
- **Array Effect / List Relay** — Free. [JSON](../nodes/graphic/arrayEffect.json) · `node:graphic:arrayEffect:listRelay`. Relay a list of Graphics. This node has no effect. Tho useful to define a type when wiring to generics.
- **Color Effect / Bayer Dither** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:bayerDither`. Applies ordered Bayer dithering to the image with adjustable strength, levels, and optional monochrome output.
- **Color Effect / Channel Mix** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:channelMix`. Mix red, green, blue and alpha channels.
- **Color Effect / Chroma Key** — Pro. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:chromaKey`. Green screen background removal.
- **Color Effect / Clamp** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:clamp`. Apply various styles to colors outside of the set range.
- **Color Effect / Color Convert** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:colorConvert`. Convert between color models. For HSV and the all channel option; hue is red, saturation is green, and value / brightness is blue.
- **Color Effect / Color Map** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:colorMap`. Map colors with a 2 stop gradient, from background to foreground.
- **Color Effect / Color Shift** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:colorShift`. Shift colors in a graphic.
- **Color Effect / Gradient Lookup** — Free; deprecated; replacement node:graphic:colorEffect:gradientLookup2. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:gradientLookup`. Lookup colors in a gradient based on luminance.
- **Color Effect / Gradient Lookup** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:gradientLookup2`. Creates a gradient from Color Stops, falling back to Gradient when the inlet is disconnected.
- **Color Effect / Levels** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:levels`.
- **Color Effect / Person Segmentation** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:personSegmentation`. Background removal.
- **Color Effect / Quantize** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:quantize`. Lowers the color detail.
- **Color Effect / Range** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:range`. Range a graphics colors from a reference low and high to a target low and high.
- **Color Effect / Relay** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:relay`. Relay a Graphic. This node has no effect. Tho useful to define a type when wiring to generics.
- **Color Effect / Saliency** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:saliency`. Detect attention or objectness of a graphic, as a monochrome heat map.
- **Color Effect / Slope** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:slope`. Calculate the slope between neighboring pixels by generating a normal map. 16 or 32 bit recommended.
- **Color Effect / Threshold** — Free. [JSON](../nodes/graphic/colorEffect.json) · `node:graphic:colorEffect:threshold`. Divide the graphic into two regions: one with a value below the threshold (background), and one with a value above (foreground).
- **Compute Effect / Dither** — Free. [JSON](../nodes/graphic/computeEffect.json) · `node:graphic:computeEffect:dither`. Dither a graphic with different algorithms.
- **Compute Effect / Flood Fill** — Free. [JSON](../nodes/graphic/computeEffect.json) · `node:graphic:computeEffect:floodFill`. Fill an area of a graphic with a color.
- **Compute Effect / Histogram** — Free. [JSON](../nodes/graphic/computeEffect.json) · `node:graphic:computeEffect:histogram`. Generate a histogram from a graphic with red, green and blue channels.
- **Convert / Analyze** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:analyze`. Combine every pixel of a graphic into a single color. Useful for auto exposure, dominant color and black and white points. The graphic is always read at its own resolution.
- **Convert / Bits** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:bits`. Change the color depth of a graphic.
- **Convert / Cartesian to Polar** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:cartesianToPolar`. Unwrap the circle at the center of a graphic into polar coordinates, keeping the resolution. The horizontal axis is a full turn from the start angle, going clockwise. The vertical axis is the radius, the top is the center and the bottom is half the height out.
- **Convert / Color Space** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:colorSpace`. Convert the light of a graphic from one color space to another, keeping the resolution and the bits.
- **Convert / Corner Pin** — Pro; deprecated; replacement node:graphic:convert:cornerPin2. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:cornerPin`.
- **Convert / Corner Pin** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:cornerPin2`. Corner pin a graphic using four unit-space points.
- **Convert / Crop** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:crop`.
- **Convert / Cube Map Components** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:cubeMapComponents`. Crop the six faces out of a cube map, a horizontal cross in a 4x3 atlas. Each face is a quarter of the width and a third of the height, seen from the outside of the cube. The opposite of Cube Map Construct.
- **Convert / Cube Map Construct** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:cubeMapConstruct`. Align six face graphics into one cube map, a horizontal cross in a 4x3 atlas. The layout matches the cube UVs, so the result can be used as a texture on a Cube node. All six graphics need the same resolution, each seen from the outside of the cube.
- **Convert / Cube Map to Equirect** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:cubeMapToEquirect`. Unwrap a cube map, laid out as a horizontal cross in a 4x3 atlas, into an equirectangular graphic. Columns are left, front, right and back, rows are top, sides and bottom. The result is twice as wide as it is tall, with the north pole at the top and the front at the center.
- **Convert / Equirect Orientation** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:equirectOrientation`. Rotate and mirror the content of an equirectangular graphic, keeping the resolution. The top is the north pole, the center is the front and the left and right edges meet at the back. The source is mirrored first and rotated second.
- **Convert / Equirect to Cube Map** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:equirectToCubeMap`. Project an equirectangular graphic onto the six faces of a cube map, laid out as a horizontal cross in a 4x3 atlas. Columns are left, front, right and back, rows are top, sides and bottom. Each face is a square quarter of the width, keeping the width of the graphic. The graphic is expected to have a 2:1 aspect ratio, with the north pole at the top and the front at the center.
- **Convert / Face Detection** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:faceDetection`. Detect faces in a graphic. The output is a list of frames and cropped graphics for each face.
- **Convert / Frame Crop** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:frameCrop`.
- **Convert / Grid Warp** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:gridWarp`. Warp a graphic through a grid of points. Connect a List State Point node to edit points. The points are expected to be in row-major order.
- **Convert / Location from Depth** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:locationFromDepth`. Reconstruct world-space location per pixel from a camera and a non-normalized depth map. XYZ as RGB.
- **Convert / Polar to Cartesian** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:polarToCartesian`. Wrap a graphic in polar coordinates into a circle at the center, keeping the resolution. The horizontal axis is a full turn from the start angle, going clockwise. The vertical axis is the radius, the top is the center and the bottom is half the height out. Outside of the circle is transparent.
- **Convert / Reduce** — Pro. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:reduce`. Combine every pixel along one axis into a single row or column. Useful for scopes and profiles. The graphic is always read at its own resolution.
- **Convert / Resolution** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:resolution`.
- **Convert / Text Detection** — Free. [JSON](../nodes/graphic/convert.json) · `node:graphic:convert:textDetection`. Detect text in a Graphic and output a keyed list whose frames identify the location of each recognized String.
- **Engine / 3D Render** — Free. [JSON](../nodes/graphic/engine.json) · `node:graphic:engine:kagamiRender`. Render 3D entities, including Gaussian splats, to a graphic in realtime. Provide at least one camera among the entities to render from. Gaussian splats appear in color output and depth-test against opaque geometry, but are currently excluded from depth output.
- **Engine / Render** — Free; deprecated; replacement node:graphic:engine:kagamiRender. [JSON](../nodes/graphic/engine.json) · `node:graphic:engine:render`. Render 3D geometry to a graphic.
- **Model / Number** — Free. [JSON](../nodes/graphic/model.json) · `node:graphic:model:number`. Detect a number with the MNIST machine learning model.
- **Modifier Effect / Blend** — Free. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:blend`. Blend two graphics together.
- **Modifier Effect / Cross** — Free. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:cross`. Average two graphics together.
- **Modifier Effect / Displace** — Free. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:displace`. Displace the first graphic with the seconds graphics red (x) and green (y) colors.
- **Modifier Effect / Frame Blend** — Pro. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:frameBlend`. Blend two graphics together and place the trailing graphic in a frame.
- **Modifier Effect / Lookup** — Free. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:lookup`. Lookup colors in the second graphic based on the first graphics luminance.
- **Modifier Effect / Luma Blur** — Pro. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:lumaBlur`. Blur the first graphic based on the second graphic's luminance.
- **Modifier Effect / Luma Color Shift** — Pro. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:lumaColorShift`. Shift colors in the first graphic based on the second graphic's luminance.
- **Modifier Effect / Luma Levels** — Pro. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:lumaLevels`. Level the first graphic based on the second graphic's luminance.
- **Modifier Effect / Luma Rainbow Blur** — Free. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:lumaRainbowBlur`. Rainbow blur the first graphic based on the second graphic's luminance.
- **Modifier Effect / Luma Transform** — Pro. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:lumaTransform`. Transform the first graphic based on the second graphic's luminance.
- **Modifier Effect / Mask** — Free; deprecated; replacement node:graphic:modifierEffect:mask2. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:mask`.
- **Modifier Effect / Mask** — Free. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:mask2`. Blends a background graphic with a foreground graphic using the mask graphic: black reveals the background and white reveals the foreground.
- **Modifier Effect / Remap** — Free. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:remap`. Remaps the main graphic by using the map graphic as mapping: red drives x and green drives y for each pixel sample. The map graphic should be in 16 or 32 bit to preserve detail. The resolution of the outlet graphic is derived from the map graphic.
- **Modifier Effect / Transform Blend** — Pro. [JSON](../nodes/graphic/modifierEffect.json) · `node:graphic:modifierEffect:transformBlend`. Blend two graphics together and apply a transform to the trailing graphic.
- **Resource / Camera** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:camera`. A live camera capture feed.
- **Resource / Convert from 3D Graphic** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:convertFromGraphic3D`. Convert a 3D graphic to a 2D graphic using trace, add, or average methods.
- **Resource / Convert from Vector** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:convertFromVector`. Convert a vector shape to a graphic. Fill or stroke with a color.
- **Resource / Convert from View** — Free; deprecated; replacement node:graphic:resource:convertFromView2. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:convertFromView`. Convert a view to a graphic.
- **Resource / Convert from View** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:convertFromView2`. Convert a view to a graphic with configurable resolution, foreground color, background color, and bit depth.
- **Resource / List State** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:listState`. Store a list of graphics.
- **Resource / Maps** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:maps`. World map. Lower the span to narrow down on a location.
- **Resource / Metadata** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:metadata`. Information about details of a graphic.
- **Resource / Paint** — Pro. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:paint`. Paint with various brushes like circle, gradient, line, and sample a another graphic. Paint is passed upstream to a State Graphic node via the source inlet. Switch between release and live paint mode. Sample over time. Interpolate between points for a more accurate path. Control active and location of the paint via inlets. Overlay a reference graphic with opacity.
- **Resource / QR Code** — Pro. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:qrCode`. Generate a QR code Graphic from a text String.
- **Resource / Scan Code** — Pro. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:scanCode`. Scan a barcode or QR code from a Graphic, update a bound String, and report whether a code was detected.
- **Resource / Screen Capture** — Pro. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:screenCapture`. Live screen capture from a display or window.
- **Resource / Slice from 3D Graphic** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:sliceFromGraphic3D`. Sample a 2D slice from a 3D graphic along a selected axis.
- **Resource / State** — Free. [JSON](../nodes/graphic/resource.json) · `node:graphic:resource:state`. Store a graphic.
- **Solid / Color** — Free; deprecated; replacement node:graphic:solid:color2. [JSON](../nodes/graphic/solid.json) · `node:graphic:solid:color`. A plain solid color, filling the area.
- **Solid / Color** — Free. [JSON](../nodes/graphic/solid.json) · `node:graphic:solid:color2`. A plain solid color, filling the area.
- **Solid / Gradient** — Free; deprecated; replacement node:graphic:solid:gradient2. [JSON](../nodes/graphic/solid.json) · `node:graphic:solid:gradient`. A gradient of colors. Match the colors inlet with the stops inlet. The stops are between zero and one.
- **Solid / Gradient** — Free. [JSON](../nodes/graphic/solid.json) · `node:graphic:solid:gradient2`. Creates a gradient from Color Stops, falling back to Gradient when the inlet is disconnected.

- **Solid / Noise** — Free. [JSON](../nodes/graphic/solid.json) · `node:graphic:solid:noise2`. Generate random, cloudy or smooth noise.
- **Space Effect / Blur** — Free. [JSON](../nodes/graphic/spaceEffect.json) · `node:graphic:spaceEffect:blur`. Blur a graphic. Gaussian blur is the fastest.
- **Space Effect / Circle Blur** — Free. [JSON](../nodes/graphic/spaceEffect.json) · `node:graphic:spaceEffect:circleBlur`. Circle blur a graphic.
- **Space Effect / Edge** — Free. [JSON](../nodes/graphic/spaceEffect.json) · `node:graphic:spaceEffect:edge`. Highlight the edges of a graphic.

- **Stack / Horizontal** — Free. [JSON](../nodes/graphic/stack.json) · `node:graphic:stack:horizontal`. Stack graphics side by side, from leading to trailing. The alignment is on the vertical axis, and the spacing is the gap between each graphic.
- **Stack / Layers** — Free. [JSON](../nodes/graphic/stack.json) · `node:graphic:stack:layers`. Stack graphics in depth, from back to front. The alignment places graphics of different resolutions, and the blend mode is used between each layer.
- **Stack / Vertical** — Free. [JSON](../nodes/graphic/stack.json) · `node:graphic:stack:vertical`. Stack graphics on top of each other, from top to bottom. The alignment is on the horizontal axis, and the spacing is the gap between each graphic.
- **System / Pixel Particles** — Pro. [JSON](../nodes/graphic/system.json) · `node:graphic:system:pixelParticles`. Every pixel in the first input graphic will become a particle in the output graphic. Red is x, green is y, and blue is scale if channel scale is on. Optionally second input graphic will be used to color each particle. Keep the resolutions of the two graphic inputs the same. Note that to have particles in locations below zero (zero is in the center), the input graphic needs to be in 16 bit or higher.
- **System / Sprites** — Pro. [JSON](../nodes/graphic/system.json) · `node:graphic:system:sprites`. Instance Graphics at specific locations with scale, rotation and opacity. The instance system will loop over the inputs if they don't have the same count.
- **Time Effect / Luma Delay** — Pro. [JSON](../nodes/graphic/timeEffect.json) · `node:graphic:timeEffect:lumaDelay`. Delay a graphic over time. The first inlet is the graphic to be delayed and the second inlet is the graphic used as a source of delay based on its luminance. Black is zero delay, gray is half delay, and white is full delay.
- **Time Effect / Optical Flow** — Free. [JSON](../nodes/graphic/timeEffect.json) · `node:graphic:timeEffect:opticalFlow`. An effect that generates directional change vectors for each pixel in the graphic over time.
- **Tracking / Body** — Pro. [JSON](../nodes/graphic/tracking.json) · `node:graphic:tracking:body`. Track a body in a Graphic. Outputs a keyed list of 19 joints, like nose and leftWrist, located in the resolution space of the Graphic. The frame is the bounding box of the tracked joints.
- **Tracking / Face** — Pro. [JSON](../nodes/graphic/tracking.json) · `node:graphic:tracking:face`. Track a face in a Graphic. Outputs a keyed list of landmarks, like outerLips.03 and leftPupil.00, located in the resolution space of the Graphic. Each region is numbered in path order.
- **Tracking / Hand** — Pro. [JSON](../nodes/graphic/tracking.json) · `node:graphic:tracking:hand`. Track hands in a Graphic. Each hand outputs a keyed list of 21 joints, like thumbTip and indexTip, located in the resolution space of the Graphic. The frame is the bounding box of the tracked joints.
- **Tracking / Human** — Pro. [JSON](../nodes/graphic/tracking.json) · `node:graphic:tracking:human`. Track people in a Graphic. Outputs a frame for each person, located in the resolution space of the Graphic. Frames are ordered from leading to trailing.
