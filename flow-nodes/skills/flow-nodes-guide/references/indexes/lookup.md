# Lookup nodes

Each linked JSON file contains a parent group. Select the entry in `nodes` with the exact listed `typePath` for ports and properties. Prefer visible replacements for new flows.

- **Effect / Apply** — Free. [JSON](../nodes/lookup/effect.json) · `node:lookup:effect:apply`. Apply a lookup to a graphic.
- **Resource / Identity** — Free. [JSON](../nodes/lookup/resource.json) · `node:lookup:resource:identity`. Create a linear identity LUT lookup.
- **Resource / State** — Free. [JSON](../nodes/lookup/resource.json) · `node:lookup:resource:state`. Store a lookup.
