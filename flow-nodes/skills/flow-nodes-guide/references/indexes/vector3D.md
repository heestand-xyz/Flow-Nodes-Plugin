# 3D Vector nodes

Read the linked JSON for exact ports and properties. Prefer visible replacements for new flows.

- **Info / Components** — Free. [JSON](../nodes/node-vector3D-info-components.json) · `node:vector3D:info:components`. Get points and closed state from a selected sub path in a 3D Vector.
- **Info / Fraction Point** — Free. [JSON](../nodes/node-vector3D-info-fractionPoint.json) · `node:vector3D:info:fractionPoint`. Get a 3D point at a fractional offset along a 3D vector path.
- **Info / Fraction Points** — Free. [JSON](../nodes/node-vector3D-info-fractionPoints.json) · `node:vector3D:info:fractionPoints`. Sample a list of 3D points along a 3D vector path using fractional spacing and phase.
- **Info / Length** — Free. [JSON](../nodes/node-vector3D-info-length.json) · `node:vector3D:info:length`. Measure the full path length of a 3D vector.
- **Info / Point** — Free. [JSON](../nodes/node-vector3D-info-point.json) · `node:vector3D:info:point`. Get a 3D point at a distance offset along a 3D vector path.
- **Info / Points** — Free. [JSON](../nodes/node-vector3D-info-points.json) · `node:vector3D:info:points`. Sample a list of 3D points along a 3D vector path using absolute spacing and phase.
- **Modifier / Combine** — Free. [JSON](../nodes/node-vector3D-modifier-combine.json) · `node:vector3D:modifier:combine`. Combine a list of 3D vectors together.
- **Modifier / Curve Subdivide** — Free. [JSON](../nodes/node-vector3D-modifier-curveSubdivide.json) · `node:vector3D:modifier:curveSubdivide`. Convert 3D vector curves into line segments by subdividing each curve.
- **Modifier / List Relay** — Free. [JSON](../nodes/node-vector3D-modifier-listRelay.json) · `node:vector3D:modifier:listRelay`. Relay a list of 3D vectors.
- **Modifier / Relay** — Free. [JSON](../nodes/node-vector3D-modifier-relay.json) · `node:vector3D:modifier:relay`. Relay a 3D vector.
- **Modifier / Transform** — Free. [JSON](../nodes/node-vector3D-modifier-transform.json) · `node:vector3D:modifier:transform`. Transform a 3D vector by position, scale, and rotation.
- **Resource / Construct** — Free. [JSON](../nodes/node-vector3D-resource-construct.json) · `node:vector3D:resource:construct`. Construct a 3D Vector from a list of 3D Vector Points.
- **Resource / Convert from Vector** — Free. [JSON](../nodes/node-vector3D-resource-convertFromVector.json) · `node:vector3D:resource:convertFromVector`. Convert a 2D Vector path into a unit-sized 3D Vector path.
- **Resource / L-System** — Free. [JSON](../nodes/node-vector3D-resource-lSystem.json) · `node:vector3D:resource:lSystem`. Create a 3D vector path from an L-system grammar. Draw forward with F, move forward without drawing with f, use + and - for yaw Z, & and ^ for pitch X, \ and / for roll Y, and [ ] for branches.
- **Resource / List State** — Free. [JSON](../nodes/node-vector3D-resource-listState.json) · `node:vector3D:resource:listState`. Store a list of 3D vectors.
- **Resource / State** — Free. [JSON](../nodes/node-vector3D-resource-state.json) · `node:vector3D:resource:state`. Store a 3D vector.
- **Shape / Helix** — Free. [JSON](../nodes/node-vector3D-shape-helix.json) · `node:vector3D:shape:helix`. Construct a spiraling helix 3D vector path.
