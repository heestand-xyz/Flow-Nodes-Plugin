# Realtime nodes

Read the linked JSON for exact ports and properties. Prefer visible replacements for new flows.

- **Communication / Connectivity** — Free. [JSON](../nodes/node-realtime-communication-connectivity.json) · `node:realtime:communication:connectivity`. Connectivity of WiFi and cellular network status with IP address information.
- **Communication / MIDI Receive** — Free. [JSON](../nodes/node-realtime-communication-midiReceive.json) · `node:realtime:communication:midiReceive`. Receive MIDI notes.
- **Communication / MIDI Receive CC** — Free. [JSON](../nodes/node-realtime-communication-midiReceiveCC.json) · `node:realtime:communication:midiReceiveCC`. Receive MIDI control changes.
- **Communication / MIDI Receive List CC** — Free. [JSON](../nodes/node-realtime-communication-midiReceiveListCC.json) · `node:realtime:communication:midiReceiveListCC`. Receive a list of MIDI control changes.
- **Communication / MIDI Transmit** — Pro. [JSON](../nodes/node-realtime-communication-midiTransmit.json) · `node:realtime:communication:midiTransmit`. Send MIDI notes.
- **Communication / MIDI Transmit CC** — Pro. [JSON](../nodes/node-realtime-communication-midiTransmitCC.json) · `node:realtime:communication:midiTransmitCC`. Send MIDI control changes.
- **Communication / NDI Receive** — Free. [JSON](../nodes/node-realtime-communication-ndiReceive.json) · `node:realtime:communication:ndiReceive`. Receive realtime graphics on the local network. NDI® is a registered trademark of Vizrt NDI AB.
- **Communication / NDI Transmit** — Pro. [JSON](../nodes/node-realtime-communication-ndiTransmit.json) · `node:realtime:communication:ndiTransmit`. Send realtime graphics over the local network. NDI® is a registered trademark of Vizrt NDI AB.
- **Communication / OSC Receive** — Free. [JSON](../nodes/node-realtime-communication-oscReceive.json) · `node:realtime:communication:oscReceive`. Receive OSC messages. To see the received value; connect the generic outlet to a relay node with the expected value type.
- **Communication / OSC State** — Pro. [JSON](../nodes/node-realtime-communication-oscState.json) · `node:realtime:communication:oscState`. Send and receive OSC messages. To see the received value; connect the generic outlet to a relay node with the expected value type.
- **Communication / OSC Transmit** — Pro. [JSON](../nodes/node-realtime-communication-oscTransmit.json) · `node:realtime:communication:oscTransmit`. Send OSC messages.
- **Home / Light** — Free. [JSON](../nodes/node-realtime-home-light.json) · `node:realtime:home:light`. Control a light in a room in your home. Powered by HomeKit.
- **Intent / Action** — Free. [JSON](../nodes/node-realtime-intent-action.json) · `node:realtime:intent:action`. Triggers an action when the Flow Nodes "Node Action" intent runs. Use the "Node Action" shortcut with the Action Button on iPhone, or use the "Node Action" intent in the Shortcuts app, or just say "Hey Siri trigger action in ".
- **Intent / Float Input** — Free. [JSON](../nodes/node-realtime-intent-floatInput.json) · `node:realtime:intent:floatInput`. Receive a float value when the Flow Nodes Node Float Input Intent runs. Use the intent with the action button on iPhone or the Shortcuts app.
- **Intent / Float Output** — Free. [JSON](../nodes/node-realtime-intent-floatOutput.json) · `node:realtime:intent:floatOutput`. Send a float value when the Flow Nodes Node Float Output Intent runs. Use the intent with the action button on iPhone or the Shortcuts app.
- **Intent / String Input** — Free. [JSON](../nodes/node-realtime-intent-stringInput.json) · `node:realtime:intent:stringInput`. Receive a string value when the Flow Nodes Node String Input Intent runs. Use the intent with the action button on iPhone or the Shortcuts app.
- **Intent / String Output** — Free. [JSON](../nodes/node-realtime-intent-stringOutput.json) · `node:realtime:intent:stringOutput`. Send a string value when the Flow Nodes Node String Output Intent runs. Use the intent with the action button on iPhone or the Shortcuts app.
- **Modulator / Noise** — Free. [JSON](../nodes/node-realtime-modulator-noise.json) · `node:realtime:modulator:noise`. Simplex noise.
- **Modulator / Wave** — Free. [JSON](../nodes/node-realtime-modulator-wave.json) · `node:realtime:modulator:wave`. A low frequency oscillator. A sine wave.
- **Sensor / Accelerometer** — Free. [JSON](../nodes/node-realtime-sensor-accelerometer.json) · `node:realtime:sensor:accelerometer`. Device accelerometer updates.
- **Sensor / Compass** — Free. [JSON](../nodes/node-realtime-sensor-compass.json) · `node:realtime:sensor:compass`. Heading of the current device.
- **Sensor / Face Tracking** — Free. [JSON](../nodes/node-realtime-sensor-faceTracking.json) · `node:realtime:sensor:faceTracking`. Track your face with the true depth camera. Get blend shapes, from mouth, eye and more.
- **Sensor / Game Controller** — Free; deprecated; replacement node:realtime:sensor:gameController2. [JSON](../nodes/node-realtime-sensor-gameController.json) · `node:realtime:sensor:gameController`. Receive signals from a bluetooth connected game controller.
- **Sensor / Game Controller** — Pro. [JSON](../nodes/node-realtime-sensor-gameController2.json) · `node:realtime:sensor:gameController2`. Choose a connected game controller device and read each controller element from its own outlet.
- **Sensor / Gyroscope** — Free. [JSON](../nodes/node-realtime-sensor-gyroscope.json) · `node:realtime:sensor:gyroscope`. Device gyroscope updates.
- **Sensor / Haptics** — Free. [JSON](../nodes/node-realtime-sensor-haptics.json) · `node:realtime:sensor:haptics`. Trigger a haptic feedback on the device.
- **Sensor / Location** — Free. [JSON](../nodes/node-realtime-sensor-location.json) · `node:realtime:sensor:location`. Geo location of the current device.
- **Sensor / Microphone** — Free. [JSON](../nodes/node-realtime-sensor-microphone.json) · `node:realtime:sensor:microphone`. Microphone audio levels.
