# Discover

Source route: `/docs/ui/discover`. Media is not bundled; public route availability must be verified.

Discover is a collection of examples, tutorials, and ready-made flows. Use it to learn Flow Nodes, explore an unfamiliar feature, or begin with an existing idea instead of an empty flow.

## Browse presets

Presets appear in a scrolling grid. They are grouped by category.

Each preset card includes a preview and the actions supported by that preset. 

## Open a preset

Depending on the preset, you can:

- Open the preset as a new demo flow.
- Open the preset with a guided tutorial.

The new flow is yours to explore and edit. Changes you make do not alter the original preset.
