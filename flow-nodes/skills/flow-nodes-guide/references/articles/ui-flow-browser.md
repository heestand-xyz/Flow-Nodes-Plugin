# Flow Browser

Source route: `/docs/ui/flow-browser`. Media is not bundled; public route availability must be verified.

Flow Browser lets you add one of your saved flows to the flow you are currently editing.

## Find a flow

Your flows and folders appear in a searchable grid.

- Select a folder to view its contents.
- Use the path bar to return to **Root** or another folder in the current path.
- Enter a name in **Search** to filter the current folder.
- Select the close button to return to the Canvas without adding anything.

Flow Browser identifies your current flow, flows that are already open, and flows that are already referenced by the current flow. A flow that is still downloading from iCloud appears as a disabled syncing item until it is ready.

## Add a copy or an instance

1. Select the flow you want to add.
2. Choose **Copy** or **Instance** when prompted.

Choose **Copy** when you want independent nodes that you can change without affecting the saved source flow.

Choose **Instance** when you want to keep a reference to the source flow. An instance remains identifiable as a reference, making it useful when the same flow is reused in several places.

Folders help you navigate but cannot be added to the Canvas from Flow Browser.
