# Home

Source route: `/docs/ui/home`. Media is not bundled; public route availability must be verified.

Home is where you create, open, organize, import, and export your flows.

## Browse your flows

Your flows and folders appear as thumbnails in an adaptive grid. A flow thumbnail can include a preview, outputs, assets, sync status, and other useful details.

- Use **Search** to filter the current folder.
- Use **Sorting** to sort by save date or name, reverse the order, or keep folders at the top.
- Use the path bar to return to the top or another folder in the current path.

When your flows are still loading from iCloud, Home displays progress or a syncing thumbnail.

## Create a flow or folder

Select **New Flow** to start a blank flow. New flows will automatically open the node creator.

[Node Creator](ui-node-creator.md)

Select **New Folder** in the toolbar to create a folder in your current location.

## Select multiple items

Use **Batch Selection** to select more than one flow or folder. You can then:

- Export the selected items.
- Remove the selected items.
- Select **Done** to leave selection mode.

Flow Nodes asks for confirmation before removing selected items.

## Import and export

Open the app menu (top left with the 3 ellipsis icon) to import a flow or export all flows in the current folder. You can also import by opening a supported Flow Nodes file or dropping files onto Home.

During a large export, Home shows the number of completed items and the overall percentage. You can cancel an export that is still in progress.

## Other options

The Home toolbar provides quick access to refresh, Settings, Flow Nodes links, onboarding, and About.

The first time you open Flow Nodes, onboarding appears automatically.
