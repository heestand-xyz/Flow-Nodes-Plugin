# Node Creator

Source route: `/docs/ui/node-creator`. Media is not bundled; public route availability must be verified.

Node Creator is the catalog of nodes you can add to a flow. Open it from the Canvas or while creating a wire.

## Find a node

Use **Search Nodes** to search by a node's name or purpose. You can also filter nodes by category.

Node Creator may show these sections:

- **Favorites** for nodes you use often. Long press or right click to favorite a node.
- **Recent** for nodes you added recently. Can be cleared in context menu of the icon.
- **Recommendations** for nodes that are commonly useful in the current connection.
- **Suggestions** for nodes with compatible inlets or outlets.
- Node families and their related groups.

Use the category control to show **Basic**, **Advanced**, or **All** nodes. If a filter has no matches, select **See All Nodes** to clear the limited view.

## Add a node

1. Open Node Creator at the location where you want the new node.
2. Search or browse for a node.
3. Select the node to add it to the Canvas.

The new node appears near the location where you opened Node Creator. The panel then closes so you can continue editing your flow.

Use the Folder and Group node shortcuts (top left) to organize existing graph content. When a node needs an imported asset, Node Creator can offer sources such as **Photos**, **Files**, or **Camera**, depending on the device and asset type.

## Create a node from a connection

When you open Node Creator from an inlet or outlet, the panel describes the connection you are making. Choose a recommended or compatible node to add it and continue the wire through the appropriate inlet or outlet.

Recommendations are based on useful connection patterns. Suggestions are based on connection compatibility. A node can therefore appear in one list, both lists, or neither list.

Flow Nodes prevents incompatible connections, including connections between static and dynamic lets that cannot work together.

## Tips

- With a hardware keyboard, start typing when the search field is focused.
- Favorite frequently used nodes for quicker access.
- If a tutorial is active, Node Creator highlights the node or section needed for the current step.
