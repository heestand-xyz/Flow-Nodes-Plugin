Source route: `/docs/info/flow-nodes-3`. Media is not bundled; public route availability must be verified.

> This is an archived guide to an earlier release. The current interface may differ. See [App Versions](https://flownodes.app/docs/versions) for release details.

[‎Flow Nodes](https://apps.apple.com/se/app/flow-nodes/id6501975062?l=en-GB)

![Flow Nodes 3.0 — step 1](https://flownodes.app/docs/media/info-flow-nodes-3/media-01.png)

New UI system with **Tabs** and **Split Views**, also adopting Liquid Glass**.** **AI** features like **chat**, generate nodes and suggestions, powered by Apple’s Foundation Models on compatible devices. **New types** like Transform, Vertex and Polygon. **New nodes** like Trigger, Transition, Light (HomeKit), JSON Encode and Decode, Color Picker, Date Picker, Dither, Sprites (2D), Clones (3D), Transcript (voice to text), and more nodes. Import and export **SVG Vector** files. Organize **Flows in Folders,** along with new **iCloud sync** improvements. **Animate** with the new time function in **scripts**, along with code syntax highlighting for **JavaScript** and **Metal**. Pick colors and other values with a new picker UI.
