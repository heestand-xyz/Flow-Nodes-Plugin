# Tutorials

Source route: `/docs/ui/tutorials`. Media is not bundled; public route availability must be verified.

Tutorials are step-by-step guides that teach you how to build and edit nodes in a flow. Each tutorial opens with a prepared flow guide and walks you through a series of actions.

## Start a tutorial

You can find tutorials in the Discover tab. Select a tutorial to open its flow, then select **Play** in the tutorial panel to begin.

Before playback begins, the panel shows the tutorial name and a short description. Your progress is preserved when you leave an ongoing tutorial and return to its flow later.

## Follow the steps

During playback, the tutorial panel describes the current action. Highlights and callouts identify the relevant part of the interface, such as a button, panel, node, or area of the Canvas.

A row of dots shows your position in the tutorial:

- Solid dots represent the current and completed steps.
- Dimmed dots represent the remaining steps.

Complete the requested action to move to the next step. The tutorial panel briefly animates when your progress changes.

## Tutorial controls

While a tutorial is playing, you can:

- Select **Pause** to stop advancing while keeping your place.
- Select **Stop** to end the tutorial.
- Select **Auto** when available to complete the current step automatically.

When paused, select **Resume** to continue or **Stop** to end the tutorial.

Automatic completion is intended for a step you cannot complete manually or when you need assistance. The button may show how many automatic completions remain.

## Complete a tutorial

After the final step, the panel indicates that the tutorial is completed. Select **Finish** to close the tutorial panel and continue exploring the flow.

Completed tutorials are marked in Discover preset cards so you can distinguish them from tutorials you have not finished.

## Accessibility

Tutorial controls provide spoken labels and hints. With larger accessibility text sizes, some controls use labeled symbols to keep the panel compact. Automatic completion remains available when accessibility features require it.
